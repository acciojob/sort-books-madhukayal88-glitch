# Book Sorting App

A React & Redux-based application that fetches book data from the New York Times Books API and allows users to sort them by Title, Author, or Publisher.

## Features

- Fetch books from NYT Books API
- Display books in a structured table
- Sort by Title, Author, or Publisher
- Ascending/Descending order support
- Redux state management
- Loading and error handling
- Responsive design
